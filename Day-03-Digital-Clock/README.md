# ⏰ Day 03 - Digital Clock

A simple Digital Clock built using **HTML, CSS, and JavaScript** as part of my **30 Days of Frontend Development Challenge**.

## 🚀 Features

- Live digital clock
- 12-hour time format
- AM / PM indicator
- Leading zeros (e.g. 09:05:07)
- Current day display
- Current date display
- Updates every second using `setInterval()`

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 📚 Concepts Practiced

- DOM Manipulation
- Date Object (`new Date()`)
- `getHours()`
- `getMinutes()`
- `getSeconds()`
- `getDay()`
- `getDate()`
- `getMonth()`
- `getFullYear()`
- Arrays
- Functions
- `setInterval()`
- Template Literals
- Ternary Operator
- `padStart()`
- Conditional Statements

## 🎯 What I Learned

During this project, I learned how to:

- Create a live updating digital clock.
- Work with the JavaScript Date object.
- Convert 24-hour time into 12-hour format.
- Display AM/PM dynamically.
- Format numbers using `padStart()`.
- Display the current day and date.
- Update the UI every second using `setInterval()`.
- Improve DOM manipulation skills.
