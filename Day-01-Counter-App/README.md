# 🚀 Day 01 - Counter App

A simple and responsive Counter App built using **HTML**, **CSS**, and **JavaScript** as part of my **30 Days of Frontend Development** challenge.

---

## 📌 Features

- ➕ Increment Counter
- ➖ Decrement Counter
- 🔄 Reset Counter
- 📱 Responsive Design
- ⚡ Instant UI Updates using JavaScript

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)

---

## 📚 Concepts Practiced

- Variables
- DOM Selection (`getElementById`)
- Event Listeners
- Arrow Functions
- DOM Manipulation (`innerText`)
- Increment (`++`) & Decrement (`--`)
- Reset Logic
- Updating the UI Dynamically

---

## 💡 What I Learned

- Selecting HTML elements using JavaScript.
- Handling click events with `addEventListener()`.
- Updating the DOM dynamically.
- The difference between changing a JavaScript variable and updating the UI.
- Writing cleaner and more readable JavaScript code.

## 🎯 Challenge

This project was built as part of my **30 Days of Frontend Development** challenge.

I did **not** copy the complete code from any tutorial. While learning, I referred to documentation and online resources to understand concepts, then implemented the logic myself.
