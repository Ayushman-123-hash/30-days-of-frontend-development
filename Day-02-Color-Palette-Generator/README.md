# 🎨 Day 02 - Color Palette Generator

A simple and interactive **Color Palette Generator** built using **HTML**, **CSS**, and **JavaScript** as part of my **30 Days of Frontend Development** challenge.

---

## 🚀 Features

- 🎲 Generate Random HEX Color
- 🎨 Change Background Color Dynamically
- 🏷️ Display Current HEX Color Code
- 📋 Copy HEX Color to Clipboard
- ✅ Copy Feedback with "Copied!" Message
- 📱 Responsive Design

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)

---

## 📚 Concepts Practiced

- DOM Selection (`getElementById`)

- `Math.random()`
